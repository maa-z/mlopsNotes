
```text
Learning Speed

Model Improvement
```

```text

```

# 6. What Are Outputs?

```python

 [0.12,0.88]
```

Usually:

```text

```

---


```text
Raw Class Scores
```

generated by final layer.

---


Possible.

# 7. Why Not Use Probabilities Directly?

Because neural networks naturally produce:

```text
Scores
```

---

CrossEntropyLoss internally converts them into:

```text
Probabilities
```

using:

```text
Softmax
```

---

Important realization:

```python
nn.CrossEntropyLoss()
```

already includes:

```text
Softmax
```

internally.

---

# Common Beginner Mistake

Wrong:

```python
outputs = softmax(outputs)

loss = criterion(
    outputs,
    labels
)
```

---

Correct:

```python
loss = criterion(
    outputs,
    labels
)
```

---

CrossEntropyLoss handles Softmax itself.

# 16. Batch Loss

Our model processes:

```python

```

```text

```

---

Example:

```text

Image 3 → 1.20

...
```

---

CrossEntropyLoss computes:

```text
Average Error
```

across batch.

---

Result:

```python

```

---

One number.

---

# 20. Training Loss vs Validation Loss

Training Loss:

```text
Error On Training Data
```

---

Validation Loss:

```text
Error On Unseen Data
```

---

Ideal:

```text
Train Loss ↓

Validation Loss ↓
```

---

Bad:

```text
Train Loss ↓

Validation Loss ↑
```

---

Meaning:

```text
Overfitting
```

# 26. Interview Questions

Q1. What is a loss function?

Answer:

A function that measures prediction error.

---

Q2. What does CrossEntropyLoss do?

Answer:

Measures classification error between predicted logits and true labels.

---

Q3. What input shape does CrossEntropyLoss expect?

Predictions:

```python
[Batch, Classes]
```

Labels:

```python
[Batch]
```

---

Q4. Does CrossEntropyLoss require Softmax beforehand?

Answer:

No.

Softmax is included internally.

---

Q5. What happens if prediction confidence for the correct class increases?

Answer:

Loss decreases.

---

Q6. Why is loss important?

Answer:

It generates gradients that guide learning.
