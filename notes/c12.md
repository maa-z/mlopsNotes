# 26. Relation To Our Training Loop

Every batch:

```python
outputs = model(images)
```

---

Loss computed:

```python
loss = criterion(
    outputs,
    labels
)
```

---

Backpropagation:

```python
loss.backward()
```

---

Updated pretrained weights:

```python
optimizer.step()
```

---

Gradually adapting EfficientNet.

# 28. Interview Questions

Q1. What is Transfer Learning?

Answer:

Using knowledge learned from one task to improve learning on another task.

---

Q2. What is a pretrained model?

Answer:

A model already trained on a large dataset.

---

Q3. What dataset are many vision models pretrained on?

Answer:

ImageNet

---

Q4. Why replace the final classifier?

Answer:

To match the number of classes in the new problem.

---

Q5. What is fine-tuning?

Answer:

Continuing training from pretrained weights.

---

Q6. What is feature extraction?

Answer:

Using pretrained layers to generate features while training only a small classifier.

---

Q7. Why is transfer learning popular?

Answer:

Less data, less compute, faster training, and usually better accuracy.
