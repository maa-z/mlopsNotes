# 7. The Simplest Optimizer

Historically:

```text
Gradient Descent
```

---

Update rule:

w_{new}=w_{old}-\eta\nabla L

---

Meaning:

```text
New Weight

=

Old Weight

-

Learning Rate × Gradient
```

---

Simple but powerful.

---

# Example

Weight:

```text
1.0
```

---

Gradient:

```text
0.2
```

---

Learning Rate:

```text
0.1
```

---

Update:

```text
1.0 - (0.1 × 0.2)

=

0.98
```

---

Weight moves slightly.

---

# 21. Why optimizer.step() Must Come After backward()

Wrong:

```python

```

---

Problem:

```text
No Gradients Exist Yet
```

---

Optimizer has:

```text
Nothing To Use
```

---

Correct:

```python
loss.backward()

optimizer.step()
```

---

Flow:

```text
Gradients First

Updates Second
```

---

# 22. Why zero_grad() Comes First

Remember:

```python
optimizer.zero_grad()
```

---

PyTorch accumulates gradients.

---

Without:

```python
zero_grad()
```

gradients become:

```text
Batch1

+

Batch2

+

Batch3
```

---

Usually incorrect.

---

Therefore:

```python
zero_grad()

↓

backward()

↓

step()
```

is the standard order.

# 27. Interview Questions

Q1. What is an optimizer?

Answer:

An algorithm that updates model parameters using gradients.

---

Q2. What does learning rate control?

Answer:

The size of parameter updates.

---

Q3. Why is Adam popular?

Answer:

It adapts learning rates and uses gradient history, making training more stable.

---

Q4. What is AdamW?

Answer:

Adam with decoupled weight decay regularization.

---

Q5. What is weight decay?

Answer:

A regularization technique that discourages excessively large weights.

---

Q6. What does optimizer.step() do?

Answer:

Updates parameters using computed gradients.

---

Q7. Does optimizer.step() compute gradients?

Answer:

No.

Gradients are computed by:

```python
loss.backward()
```
