Project A needs:

```text id="c8n4qs"

```

Project B needs:

```text id="d9k1vh"

```

Same Python.

Potential conflict.

---

# Example

```bash id="t7m5xr"

```

---

Later:

```bash id="u4n8kc"

```

Now:

```text id="q6f2jb"
Project A Breaks
```

because its dependency changed.

---

# Real World Consequence

Without isolation:

```text id="w1p7eq"
Project A
breaks

Project B
breaks

Nobody knows why
```
