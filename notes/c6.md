# 4. Linux File System

Windows:

```text id="f8ap4m"

D:\

```

Linux:

```text id="7n6o8j"
/
```

Everything starts from:

```text id="i4l8kx"

```

represented by:

```text id="f9l0es"
/
```

---



# 5. Absolute Path

Full path from root.

Example:

```text id="5s6f0z"
/home/ubuntu/animal-classifier/train.py
```

Absolute paths always begin with:

```text id="0m7jdu"
/
```

---

# 6. Relative Path

Path relative to current location.

Example:

```text id="v6a0mk"
dataset/Cat
```

This depends on where you currently are.

---

# Example

Current directory:

```text id="6w4slm"
/home/ubuntu/animal-classifier
```

Then:

```text id="n8o6ax"
dataset/Cat
```

means:

```text id="o9m1et"
/home/ubuntu/animal-classifier/dataset/Cat
```

# 27. Interview Questions

Q1. Difference between absolute and relative paths?

Absolute:

Starts from root (/).

Relative:

Starts from current directory.

---

Q2. What does pwd do?

Prints current working directory.

---

Q3. Difference between cp and mv?

cp:

Copies.

mv:

Moves or renames.

---

Q4. What does chmod do?

Changes file permissions.

---

Q5. Why use grep?

Search text inside files.

---

Q6. Why use head and tail?

Inspect beginning or end of files without opening entire file.
