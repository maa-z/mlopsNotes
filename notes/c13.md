# Our Training Loop

This was the heart of our project:

```python
for images, labels in train_loader:

    images = images.to(device)
    labels = labels.to(device)

    optimizer.zero_grad()

    outputs = model(images)

    loss = criterion(
        outputs,
        labels
    )

    loss.backward()

    optimizer.step()
```

Every weight update happened here.

Every improvement happened here.

Every learned feature happened here.

# 9. optimizer.zero_grad()

Code:

```python
optimizer.zero_grad()
```

---

One of the most misunderstood lines.

---

Question:

Why not remove it?

---

Because PyTorch accumulates gradients.

---

Example

Batch 1:

```text
Gradient = 5
```

---

Batch 2:

Without zero_grad:

```text
Gradient = 5 + 3
```

---

Batch 3:

```text
Gradient = 5 + 3 + 4
```

---

Gradients keep accumulating.

---

Usually we want:

```text
Fresh Gradient

Per Batch
```

---

Therefore:

```python
optimizer.zero_grad()
```

clears previous gradients.

---

# Visual

```text
Old Gradient

↓

Delete

↓

New Batch

↓

Compute New Gradient
```

# 25. Common Beginner Mistakes

Mistake 1

Forget:

```python
optimizer.zero_grad()
```

---

Gradients accumulate unexpectedly.

---

Mistake 2

Forget:

```python
loss.backward()
```

---

No gradients.

No learning.

---

Mistake 3

Forget:

```python
optimizer.step()
```

---

Gradients exist.

Weights never update.

---

Mistake 4

Call:

```python
optimizer.step()
```

before:

```python
loss.backward()
```

---

Mistake 5

Think:

```text
Forward Pass
=
Learning
```

---

Actually:

```text
Backward Pass
+
Optimizer Step
=
Learning
```

# 27. Interview Questions

Q1. What is an epoch?

Answer:

One complete pass through the dataset.

---

Q2. What is a batch?

Answer:

A subset of training samples processed together.

---

Q3. Why call optimizer.zero_grad()?

Answer:

To clear accumulated gradients before computing new ones.

---

Q4. What happens during the forward pass?

Answer:

The model generates predictions from inputs.

---

Q5. What does loss represent?

Answer:

How wrong the model's predictions are.

---

Q6. What does loss.backward() do?

Answer:

Computes gradients for all trainable parameters.

---

Q7. What does optimizer.step() do?

Answer:

Updates model weights using computed gradients.
