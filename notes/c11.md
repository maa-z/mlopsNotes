# Chapter 11 — Tensor Shape Mastery

# 1. Why This Chapter Matters

If I had to choose one topic that causes the most confusion in PyTorch, it would be:

```python
tensor.shape
```

Most beginner errors look like:

```text
Size Mismatch

Dimension Mismatch

Shape Error

Expected [32,2]
Got [32]
```

or

```text
Expected 4 Dimensions

Got 3 Dimensions
```

Almost all of these errors come from not understanding tensor shapes.

---

# A Senior ML Engineer Secret

Most debugging sessions start with:

```python
print(tensor.shape)
```

not:

```python
print(tensor)
```

Because:

```text
Shape
=
Structure

Values
=
Content
```

Structure is usually the problem.

---

# 2. What Is A Shape?

Example:

```python
x = torch.tensor([
    [1,2,3],
    [4,5,6]
])
```

Shape:

```python
x.shape
```

Output:

```python
torch.Size([2,3])
```

Meaning:

```text
2 Rows

3 Columns
```

---

# Shape Tells Us

Not:

```text
What Numbers Exist
```

but:

```text
How Numbers Are Organized
```

# 23. Debugging Strategy

Whenever something fails:

Print:

```python
print(images.shape)

print(outputs.shape)

print(labels.shape)
```

---

90% of PyTorch bugs become obvious.

---

# Senior Engineer Rule

Never guess shapes.

Always print them.

# 24. Common Shape Errors

Error:

```text
Expected [32,2]

Got [32]
```

Meaning:

Wrong prediction shape.

---

Error:

```text
Expected 4D Input
```

Meaning:

Missing batch dimension.

---

Error:

```text
Expected device cuda

Got cpu
```

Different problem.

Not shape.

# 25. Interview Questions

Q1. What does shape [32,3,224,224] mean?

Answer:

32 images, 3 channels, height 224, width 224.

---

Q2. Why does model output [32,2]?

Answer:

32 samples and 2 class scores per sample.

---

Q3. Why are labels shape [32]?

Answer:

One class index per sample.

---

Q4. What shape does CrossEntropyLoss expect?

Predictions:

```python
[Batch,Classes]
```

Labels:

```python
[Batch]
```

---

Q5. Why use argmax(dim=1)?

Answer:

To select the highest scoring class for each sample.
