# 24. Why optimizer.zero_grad()

PyTorch accumulates gradients.

Meaning:

```text id="m8q3xt"
New Gradient
+
Old Gradient
```

---

Without:

```python id="t5m1pk"

```

gradients keep growing.

---

Therefore:

```python id="u7q9wr"
zero_grad()
↓
backward()
↓
step()
```

every batch.
