# 2. What Problem Does Cloud Computing Solve?

Imagine you want to train an ML model.

You have two options.

Option 1:

Use your personal laptop.

Option 2:

Rent computing resources from someone else.

Historically companies purchased:

* Servers
* Networking equipment
* Storage devices
* Backup infrastructure

and installed them in physical data centers.

Example:

```text
Company
│
├── Physical Server
├── Physical Storage
├── Networking Equipment
├── Cooling System
└── Security System
```

This approach had major problems:

### Problem 1: Expensive

You must purchase hardware before using it.

Example:

```text
Need 1 Server
↓
Buy Server
↓
Pay Upfront
```

Even if the server remains idle.

---

### Problem 2: Scaling Is Slow

Imagine:

```text
100 Users Today
10000 Users Tomorrow
```

You suddenly need:

* More CPUs
* More RAM
* More Storage

Traditional scaling might take weeks.

---

### Problem 3: Maintenance

Someone must manage:

* Hardware failures
* Disk failures
* Power outages
* Networking issues

---

### Problem 4: Global Reach

Suppose users are located in:

* India
* USA
* Germany

Your server in one country may be slow for users elsewhere.

---

Cloud computing solves these problems.

---

# 3. What Is Cloud Computing?

Cloud computing means:

```text
Rent Computing Resources
Instead of Owning Them
```

Think of electricity.

You do not build your own power plant.

You simply consume electricity.

Cloud works similarly.

You do not buy:

* Servers
* Data Centers
* Networking Hardware

Instead:

```text
AWS Owns Infrastructure
↓
You Rent What You Need
```

---

AWS stands for:

```text

```

AWS is a cloud platform.

AWS provides hundreds of services.

Examples:

```text
Compute
Storage
Networking
Databases
Machine Learning
Monitoring
Security
Analytics
```

Instead of building infrastructure yourself:

```text
You Use AWS Services
```

---

# 5. The Core AWS Philosophy

AWS follows:

```text
Pay For What You Use
```

Example:

Instead of purchasing:

```text
$10,000 Server
```

you might pay:

```text
$0.10/hour
```

for a virtual machine.

This dramatically reduces startup costs.

---

# 6. AWS Global Infrastructure

AWS operates data centers around the world.

AWS infrastructure consists of:

```text
Regions
↓
Availability Zones
↓
Data Centers
```

Understanding this hierarchy is extremely important.

---

# 7. Region

A Region is a geographical location.

Examples:

```text
us-east-1
us-west-2
eu-west-1
ap-south-1
```

For India:

```text
ap-south-1
(Mumbai)
```

Think:

```text
World
↓
Country/Area
↓
Region
```

A region contains multiple Availability Zones.

---

# 8. Availability Zone (AZ)

An Availability Zone is an isolated facility within a region.

Example:

```text
ap-south-1a
ap-south-1b
ap-south-1c
```

Each AZ contains:

* Power
* Networking
* Cooling
* Physical Hardware

independent from other AZs.

Why?

Because failures happen.

Example:

```text
Fire
Flood
Power Failure
Network Failure
```

AWS wants applications to survive such failures.

---

# 9. Data Center

Inside each Availability Zone are actual physical buildings.

Those buildings contain:

```text
Servers
Storage Devices
Networking Equipment
```

This is the real hardware.

Everything else in AWS is built on top of these resources.

---

# 10. AWS Shared Responsibility Model

One of the most important AWS concepts.

Many beginners think:

```text
AWS Handles Everything
```

Wrong.

Responsibility is shared.

---

AWS manages:

```text
Physical Hardware
Networking
Data Centers
Power
Cooling
```

You manage:

```text
Applications
Data
IAM Permissions
Operating Systems
Configurations
```

Think:

```text
AWS Secures The Cloud

You Secure What Is In The Cloud
```

This idea appears everywhere in AWS.

# 15. Interview Questions

Q1. What is cloud computing?

Answer:

Renting computing resources instead of owning physical infrastructure.

---

Q2. What is a Region?

Answer:

A geographical area containing multiple Availability Zones.

---

Q3. What is an Availability Zone?

Answer:

An isolated facility within a region designed to improve fault tolerance.

---

Q4. What is the AWS Shared Responsibility Model?

Answer:

AWS secures the cloud infrastructure while customers secure their applications, data, and configurations.

---

Q5. What AWS services are commonly used in MLOps?

Answer:

IAM, S3, EC2, ECR, SageMaker, and CloudWatch.
