# 6. Compare Training vs Validation

Training:

```python
model.train()

optimizer.zero_grad()

outputs = model(images)

loss = criterion(
    outputs,
    labels
)

loss.backward()

optimizer.step()
```

---

Validation:

```python
model.eval()

with torch.no_grad():

    outputs = model(images)

    loss = criterion(
        outputs,
        labels
    )
```

---

Notice:

Missing:

```python
loss.backward()

optimizer.step()
```

---

Why?

Because:

```text
Validation Is Testing

Not Learning
```

---

# 8. Understanding Dropout

Recall:

```python
Dropout(
    p=0.2
)
```

---

Training Mode:

```text
Randomly Disable
20% Of Neurons
```

---

Purpose:

```text
Prevent Overfitting
```

---

Validation Mode:

```text
Use All Neurons
```

---

Reason:

We want:

```text
Stable Evaluation
```

---

Therefore:

```python
model.eval()
```

is mandatory.

---

# 11. What Happens During Validation?

Step 1

Load validation batch.

---

Step 2

Forward pass.

```python
outputs = model(images)
```

---

Step 3

Calculate loss.

```python
loss = criterion(
    outputs,
    labels
)
```

---

Step 4

Calculate predictions.

```python
_, preds = torch.max(
    outputs,
    dim=1
)
```

---

Step 5

Track metrics.

---

No learning occurs.

---

# 12. Validation Loss

Example:

```python
valid_loss += (
    loss.item() * images.size(0)
)
```

---

Purpose:

```text
Accumulate Error
Across Entire Validation Set
```

---

Eventually:

```python
valid_loss = (
    valid_loss
    /
    valid_total
)
```

---

Produces:

```text
Average Validation Loss
```

---

# Example

Output:

```text
Valid Loss: 0.0351
```

---

Meaning:

```text
Very Small Error
```

on unseen validation data.

# 26. Interview Questions

Q1. What is validation?

Answer:

Evaluation on unseen data during training.

---

Q2. Why use model.eval()?

Answer:

To disable training-specific behavior such as Dropout.

---

Q3. Why use torch.no_grad()?

Answer:

To avoid gradient computation and save memory.

---

Q4. What is overfitting?

Answer:

When a model performs well on training data but poorly on unseen data.

---

Q5. What is generalization?

Answer:

The ability to perform well on new unseen samples.

---

Q6. Why save the model using validation loss?

Answer:

Validation metrics better represent real-world performance.

---

Q7. Why not use the test set every epoch?

Answer:

To keep the final evaluation unbiased.
